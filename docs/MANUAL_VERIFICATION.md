## Fixes found during this review

- Hidden library source filters no longer suppress Templates or Trash.
- Document metadata and preference updates merge the current encrypted record instead of overwriting unrelated concurrent changes. Removed documents cannot be resurrected by a stale dialog.
- Releasing a local editing lock is asynchronous. A new editor mount now waits for its own previous cleanup; a genuinely concurrent writer remains blocked. Retry editing no longer reloads the page and unnecessarily locks the vault.
- Settings theme buttons expose their selected state; off-state toggles have stronger contrast, including high-contrast mode.
- The compact Shapes button now has an accessible name. Highlight opacity uses a step that represents its 32% initial value correctly.
- Prepared encrypted exports retain an explicit download link until dismissed or the editor closes. This improves recovery but does not establish delivery in the in-app browser.
